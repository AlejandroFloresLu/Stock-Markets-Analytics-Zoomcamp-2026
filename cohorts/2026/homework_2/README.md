# Homework 2

This module focuses on data wrangling and quantitative analysis using financial market data.

## Technologies Utilized
- **Python**
- **Pandas**
- **Numpy**
- **PyArrow**
- **yfinance**

## Challenges Solved
- **Data Cleaning of IPOs:** Processed and cleansed initial public offering data for analysis.
- **Sharpe Ratio Calculation:** Implemented the financial metric to understand the return of an investment compared to its risk.
- **RSI-based Trading Simulation:** Simulated trading operations leveraging the Relative Strength Index (RSI) momentum oscillator.
